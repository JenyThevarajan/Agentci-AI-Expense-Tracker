# Smart Expense Management Portal

## Objective

Build a web application that allows employees to track expenses.

## Features

1. Add Expense

Fields:
- Title
- Amount
- Category
- Date

2. View Expenses

Display all expenses.

3. Filter Expenses

Filter by category.

4. Dashboard

Display:
- Total Expenses
- Expenses per Category

## Technical Stack

Backend:
- FastAPI

Database:
- SQLite

Frontend:
- Bootstrap (FastAPI interface)
- Streamlit (optional Community Cloud interface)

Testing:
- Pytest

Deployment:
- Docker
- Streamlit Community Cloud (optional demonstration deployment)

## Security

- Input Validation
- Error Handling
- Secure Coding
